Below is the consolidated master scrape inventory for RoboPartPicker. It combines the original detailed source list, the refined product architecture, and the additional file formats and workflows discussed later.

The scraping agent should collect raw source material plus structured extracted records. Every record should retain provenance so RoboPartPicker can distinguish manufacturer claims, reported experiences, measured tests, marketplace listings, and AI inferences.
