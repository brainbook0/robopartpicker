## Maintenance rule

Do not hand-maintain all 608 views independently. Maintain canonical source, object, evidence, adapter, workflow, and decision records once. Generate these lists as filtered views wherever possible. A list that cannot name its source of truth, owner, refresh rule, and decision use should remain deferred instead of becoming another stale document.
